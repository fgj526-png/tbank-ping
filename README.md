# tbank-ping

Внешний пингер дашборда торгового робота (приватный URL в секрете `PING_URL`).

- Каждые 5 минут GitHub Actions дергает `/ping` — бодрит Passenger и фиксирует
  доступность (красный запуск = дашборд недоступен с внешней сети).
- Раз в неделю job `heartbeat` делает пустой коммит, чтобы GitHub не отключил
  расписание (правило 60 дней неактивности).

Публичный репозиторий намеренно: публичные репо не расходуют лимит минут Actions.
